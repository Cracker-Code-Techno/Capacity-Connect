CAPACITY CONNECT — Technology Stack & Architecture Reference
Project by: Code Crackers
Live Demo: https://capacity-connect.vercel.app

================================================================================
1. CORE ARCHITECTURE & RUNTIME
================================================================================
- Framework: Next.js 16.3.3 (App Router with React Server Components & Server Actions)
- UI Library: React 19.2.8 / React DOM 19.2.8
- Language: TypeScript 5.x (Strict mode, ES2022 target)
- Runtime: Node.js 20+ (Serverless Edge & Node runtime compatibility)
- Package Manager: npm

================================================================================
2. FRONTEND & USER INTERFACE
================================================================================
- Styling & Engine: Tailwind CSS v4 (via @tailwindcss/postcss, CSS variables design tokens in globals.css)
- Motion & Animation: Framer Motion 13.1.1 (Page transitions, interactive cards, micro-interactions, drag-and-drop reordering)
- Iconography: Lucide React 1.38.0 (Modern, tree-shakable SVG icon set)
- Theming: Next Themes 0.4.6 (Dark mode, Light mode, and system preference detection with zero hydration flicker)
- Typography: Geist Sans & Geist Mono (via next/font/google)
- Responsive Design: Mobile-first responsive layouts across mobile, tablet, and desktop viewports

================================================================================
3. DATABASE & PERSISTENCE
================================================================================
- Database: PostgreSQL (Hosted on Supabase)
- Connection Strategy:
  * Pooled Connection: PgBouncer (capacity_connect_POSTGRES_PRISMA_URL) for low-latency serverless query handling
  * Direct Connection: Direct TCP (DIRECT_URL) for schema migrations and CLI operations
- ORM: Prisma ORM 5.10.0 (@prisma/client, prisma CLI)
- Schema: 16 relational models including Users, Profiles, Courses, Modules, Assessments, Questions, Options, Attempts, Enrollments, Progress, Feedback, Resources, Subjects, Competencies, Highlights, and Auth Tokens
- Database Seeding: tsx prisma/seed.ts with automated demo accounts (Admin, Trainer, Trainee), announcements, and sample courses

================================================================================
4. BACKEND & API ARCHITECTURE
================================================================================
- Architecture: Next.js App Router Serverless Route Handlers (40+ REST API endpoints)
- Route Groups & Routing:
  * Public routes: Course catalog, subjects directory, trainer profiles, marketing pages
  * Protected route groups: (auth), (dashboard) [admin, trainer, trainee]
- Validation: Zod 4.5.4 (Strict client/server schema validation for forms, mutations, and API requests)
- Object & File Storage:
  * Production: @vercel/blob 2.8.0 (Vercel Blob cloud storage with edge-optimized CDN delivery)
  * Local Development Fallback: Local file system (public/uploads/) when BLOB_READ_WRITE_TOKEN is not supplied

================================================================================
5. AUTHENTICATION & SECURITY
================================================================================
- Authentication Engine: NextAuth.js 4.24.15 (Credentials Provider with JWT session strategy)
- Password Hashing: bcryptjs 3.0.3 (Salted bcrypt hash with 10 rounds)
- Middleware & Proxy: Next.js 16 proxy convention (`src/proxy.ts` exporting `proxy()`)
- Role-Based Access Control (RBAC):
  * ADMIN: Global governance, user management, CMS, competency match, announcements
  * TRAINER: Course creation, assessment grading, module resources, profile management
  * TRAINEE: Course enrollment, module progression, assessment attempts, ratings, certification
- CSRF Protection: Strict Origin / Referer validation for mutating requests (POST, PUT, PATCH, DELETE) in proxy.ts
- Rate Limiting: In-memory sliding-window rate limiter on sensitive endpoints (login: 5 req/15 min, registration, password reset)
- HTTP Security Headers: Content-Type nosniff, X-Frame-Options DENY, Referrer-Policy strict-origin-when-cross-origin
- Domain Image Protection: Next.js remotePatterns whitelist (Unsplash, Supabase, GitHub, Vercel Blob)

================================================================================
6. COMMUNICATIONS & EMAIL
================================================================================

- Workflows:
